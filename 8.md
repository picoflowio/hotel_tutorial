## Run the scenario

The HotelFlow E2E scenario drives fourteen turns through the real NestJS
application:

```sh
npm run test:hotel-flow
```

It covers criteria collection, a same-turn room change and search, initial and
repeated comparisons, resuming booking, and final completion. The test pins
the conversation date to July 15, 2027 and uses a model judge to score semantic
output; it skips live execution when required credentials are unavailable.

---
## Test transitions and state, not only words

For each new route, verify:

- the model has the correct tool and argument schema;
- invalid or no-result input returns `stay(...)` with actionable feedback;
- the expected next step becomes active after `go(...)`;
- durable criteria, result lists, selected hotels, and booking values are
  owned by the correct step;
- re-entered stages have the intended memory behavior; and
- completion and the session ID are correct.

HotelFlow is intentionally multi-turn. The same session header must be reused
until `completed` is true.
