## What HotelFlow demonstrates

`HotelFlow` is a transactional, resumable conversation. It gathers a stay date
range, nightly budget, room type, amenities, and distance preferences. It then
searches a bundled Portland-area catalog, lets the user compare options, return
to search, or choose a hotel, and completes through `TerminateSessionStep`.

The demo catalog and pricing logic are local. They illustrate workflow design,
not a live hotel inventory or production booking integration.

---
## Prerequisites

1. Node.js v22 (22.5 or later); use Node 22 for this tutorial.
2. A PicoFlow key (`PICOFLOW_KEY`).
3. An OpenAI API key for the models used by this flow.
4. A session store: SQLite for local development, or MongoDB/Cosmos DB for a
   durable shared deployment.

The session store is separate from hotel data. Do not create or populate a
`hotels` collection; the demo reads its catalog from `data/hotels.json`.

Create `.env` from the reference project's `.env-example`:

```text
PICOFLOW_KEY=<key>
OPENAI_API_KEY=<key>

DOCUMENT_DB=SQLITE
SQLITE_PATH=ignore/session/session.sqlite
SESSION_EXPIRATION=50000
```

## Run the application

```sh
npm install
npm run start:dev
```

The NestJS application listens on port 8000 and serves Swagger documentation
at `/api`.

Start a HotelFlow session:

```sh
curl -i http://localhost:8000/ai/run \
  -H 'content-type: application/json' \
  -d '{"flowName":"HotelFlow","message":"Hi","config":{}}'
```

Save the `CHAT_SESSION_ID` response header and send it with every later turn.
Use `HOTEL_FLOW_CURRENT_DATE` to pin the date for repeatable, date-sensitive
local tests.
